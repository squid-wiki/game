# 第 2 篇：穿过月见山，打华蓝市道馆

上一篇拿到了灰色徽章，这一篇从深灰市往东，穿过**月见山**，到华蓝市挑战第二个道馆馆主**小霞**。她的王牌是 **Lv21 的宝石海星**，还会"自我再生"回血。

读完你会知道：

- 3 号道路、月见山、4 号道路一路能抓什么、捡什么；
- 月见山里的**化石该选哪个**（只能选一个）；
- 4 号道路上一个**跳下去就回不去**的台阶；
- 三只御三家各自怎么打小霞，选了小火龙要带谁补位。

:::info 版本
按 Switch 版《宝可梦 火红 / 叶绿》（内容同 GBA 版）写。两版野生宝可梦不同的地方会单独标出。
:::

## 路线总览：6 步到第二馆

[![自绘路线示意图：深灰市往东经3号道路到月见山门口的宝可梦中心，穿过月见山后走4号道路到华蓝市，华蓝市往北过金球大桥是可选的24号道路。](/img/pokemon/firered/guides/gym2-route.jpg)](/img/pokemon/firered/guides/gym2-route.jpg "点击查看大图")

1. 深灰市往东走 3 号道路，8 个训练家，最高 Lv14；
2. 月见山门口的宝可梦中心，$500 能买一条鲤鱼王；
3. 月见山 1F → B1F → B2F，打败火箭队和理科男，化石二选一；
4. 出山走 4 号道路，**往下跳台阶就回不去**；
5. 可选：华蓝市往北过金球大桥，去 24 号道路抓草系；
6. 华蓝道馆挑战小霞。

## 1. 3 号道路和 4 号道路

### 能抓什么

| 地点 | 野生宝可梦 | 等级 | 出现率 |
|---|---|---|---|
| 3 号道路 | 烈雀 / 波波 | 6–8 / 6–7 | 35% / 30% |
| | 胖丁 / 猴怪 | 3–7 / 7 | 各 10% |
| | 尼多朗 / 尼多兰 | 6–7 | 火红 14% / 1%，叶绿相反 |
| 4 号道路 | 小拉达 / 烈雀 | 8–12 | 各 35% |
| | 阿柏蛇（火红）/ 穿山鼠（叶绿） | 6–12 | 25% |
| 24 号道路（金球大桥北边） | 走路草（火红）/ 喇叭芽（叶绿） | 12–14 | 25% |
| | 凯西 | 8–12 | 15% |

3 号道路有 8 个训练家，最高 Lv14，正好练级。尼多朗、尼多兰两版都有，只是出现率互换。

### 月见山门口：要不要买鲤鱼王？

月见山入口旁的宝可梦中心里，有位大叔卖**鲤鱼王**，$500 一条。鲤鱼王 Lv20 进化成**暴鲤龙**，物攻 125，听起来很划算——**但前期其实不好用**：

- 第三世代的招式按**属性**分物理 / 特殊，水系和恶系招式都算特殊，而暴鲤龙特攻只有 60；
- 它前期能学的"咬住""龙卷风"都是特殊招式，物攻 125 派不上用场；
- 能发挥物攻的招式（怪力、地震、报恩等）都在中后期才拿得到。

所以买不买随意，**别指望它推前期剧情**。想要前期好用的水系，叶绿玩家可以等拿到厉害钓竿后钓**海星星**进化成宝石海星；陆地上**尼多王**（3 号道路的尼多朗用月之石进化）也很顺手。

## 2. 月见山

月见山有三层：1F、B1F、B2F。B2F 有 4 个火箭队手下（Lv11–13）和一个理科男，打赢理科男就能选化石。

[![自绘月见山三层示意图：1F标出神奇糖果、离洞绳、招式学习器09、月之石、伤药、解麻药6个道具；B2F标出招式学习器46、星星碎片、活力碎片、解毒药、隐藏月之石、隐藏PP单项小补剂。](/img/pokemon/firered/guides/gym2-mt-moon.jpg)](/img/pokemon/firered/guides/gym2-mt-moon.jpg "点击查看大图")

| 4 | 1F | 月之石 | 登山男北边 |
| 5 | 1F | 伤药 | 理科男西北 |
| 6 | 1F | 解麻药 | 1F 西边 |

B1F 的石头上还藏着**小蘑菇、大蘑菇**（隐藏，可以重复捡），留着卖钱。隐藏道具都要站在旁边、面向那一格按 A。

**月之石**有什么用？皮皮、胖丁、尼多娜、尼多力诺进化都靠它。

### 化石只能选一个

在 B2F 打败理科男后，地上有两块化石，二选一：

| 化石 | 位置 | 复活成 |
|---|---|---|
| 甲壳化石 | 左边那块 | 化石盔（岩石 / 水） |
| 贝壳化石 | 右边那块 | 菊石兽（岩石 / 水） |

化石**现在不能复活**，要到很后面的红莲镇研究所（得会冲浪才去得了），先收在包里。另一块拿不到，随你喜好选。

### 洞里能抓什么（火红、叶绿相同）

| 层 | 野生宝可梦 | 等级 | 出现率 |
|---|---|---|---|
| 1F | 超音蝠 / 小拳石 | 7–10 / 7–9 | 69% / 25% |
| | 派拉斯 / 皮皮 | 8 | 5% / 1% |
| B1F | 派拉斯 | 5–10 | 100% |
| B2F | 超音蝠 / 小拳石 | 8–11 / 9–10 | 49% / 30% |
| | 派拉斯 / 皮皮 | 10–12 | 15% / 6% |

想要**皮皮**就去 B2F 刷，出现率 6%，比 1F 的 1% 高很多。

## 3. 4 号道路和华蓝市

出了月见山就是 4 号道路东段。这里有一段**台阶只能往下跳**，跳下去就回不到月见山那边了。买鲤鱼王、在月见山练级，都要在跳之前做完。

### 沿途白拿

1. **招式学习器05 吼叫**：4 号道路，第二层段差上；
2. **超级球**（隐藏）：4 号道路，两个格斗家西北方台阶下的角落；
3. **神奇糖果**（隐藏）：华蓝市徽章大叔家后院，五朵花最中间那朵下面；
4. **金珠**：打完金球大桥上的训练家送（能卖钱）。

华蓝市的友好商店新上架了**好伤药**（$700）。

### 往北：金球大桥和 24 号道路

华蓝市往北是金球大桥，上桥会被劲敌青绿拦下。他这时有 **4 只宝可梦，王牌是御三家 Lv18**。打赢后过桥，再往北就是 24 号道路，能抓草系的**走路草**（火红）或**喇叭芽**（叶绿）——选了小火龙的人很需要它。

## 4. 华蓝道馆：小霞

[![华蓝道馆一览：泳裤小伙子墨海马、大舌贝Lv16，野餐女孩角金鱼Lv19；小霞海星星Lv18、宝石海星Lv21及招式；奖励蓝色徽章、招式学习器03水之波动、2100元。](/img/pokemon/firered/guides/gym2-misty.jpg)](/img/pokemon/firered/guides/gym2-misty.jpg "点击查看大图")

| 训练家 | 宝可梦 | 等级 |
|---|---|---|
| 泳裤小伙子 | 墨海马 / 大舌贝 | 16 / 16 |
| 野餐女孩 | 角金鱼 | 19 |
| **小霞** | 海星星（水） | 18 |
| **小霞** | 宝石海星（水 / 超能力） | 21 |

小霞两只宝可梦的招式：

- 海星星：撞击、变硬、**自我再生**、水之波动；
- 宝石海星：高速旋转、高速星星、**自我再生**、水之波动。

**难点在"自我再生"**：每用一次回一半 HP，伤害打得不够快，就会被它回血拖住。打法是**先麻痹或催眠，再用克制招式一口气打完**，主力练到 Lv20 上下。

### 三只御三家怎么打

| 御三家 | 难度 | 怎么打 |
|---|---|---|
| 妙蛙种子 | 最轻松 | 藤鞭打两只都是 2 倍；宝石海星的水之波动打它只有 0.5 倍 |
| 杰尼龟 | 要换招 | 水打水只有 0.5 倍。进化成卡咪龟后 Lv19 学"咬住"，恶系打宝石海星（超能力）是 2 倍 |
| 小火龙 | 最难 | 火打水 0.5 倍，金属爪打宝石海星也只有 0.5 倍，水之波动打它 2 倍。**别硬冲，带队友补位** |

### 补位：带一只草系或电系

| 宝可梦 | 哪里抓 | 怎么用 |
|---|---|---|
| 皮卡丘（电） | 常青森林，5% | 电击打两只都是 2 倍；先用 Lv8 学的电磁波把对手麻痹，再慢慢打 |
| 走路草（火红）/ 喇叭芽（叶绿）（草） | 24 号道路，Lv12–14 | 走路草用吸取、喇叭芽用藤鞭，都是 2 倍 |

> 倍率只算属性克制，实际伤害还要看等级和能力。

### 打赢之后

- **蓝色徽章**：野外能用"居合劈"；换来的宝可梦 Lv30 以下会听你的话。
- **招式学习器03 水之波动**。
- 奖金 **$2100**。

## 卡点速查

| 卡住的现象 | 怎么办 |
|---|---|
| 4 号道路跳下去回不去了 | 台阶是单向的。买鲤鱼王、在月见山练级，都要在跳之前做完 |
| 化石在哪复活？ | 后面的红莲镇研究所，现在先收着 |
| 华蓝市往北被拦住 | 劲敌青绿在桥头，4 只，王牌御三家 Lv18 |
| 自行车店的车买不起 | 正常，后面拿到自行车兑换券再来换（见[必拿道具](../items/key-items.md)） |
| 居合劈在哪？ | 蓝色徽章只是让它能在野外用；居合劈本身要到圣特安努号拿（见[秘传招式](../tm-hm/hidden-machines.md)） |

## 本篇小结

带一只草系或电系，小霞就不难；小火龙别硬冲。到这里你应该有两枚徽章、一块化石，队伍主力在 Lv20 上下。
