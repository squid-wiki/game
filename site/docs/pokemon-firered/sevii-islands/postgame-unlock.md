# 通关后怎么解锁：8 步拿到超梦

"四岛去不了""大木博士不给全国图鉴""有船票却去不了肚脐岩"——火红叶绿通关后的卡点，其实都在**同一条链**上。按顺序走完下面 8 步，超梦、三圣兽和船票神兽全部解锁。

先认识两个地方：

- **七之岛**：关都南边的 7 个小岛，火红叶绿新加的地区。打赢第七馆夏伯后能去第一到第三岛，通关后才陆续开放第四到第七岛。岛和岛之间**坐船**。
- **锦辉**：第一岛宝可梦中心里修网络机器的人，整条链的任务大多是他托付的。

## 前半：先拿全国图鉴（第 1–4 步）

### 1. 陨石剧情（通关前就能做）

打赢夏伯后，跟正辉坐船去**第一岛**。锦辉托你把**陨石**交给第二岛欢乐游戏城的老板。老板的女儿**小迷**在第三岛**树果森林**迷路了，要先救出小迷才能交。

### 2. 全国图鉴

满足两个条件：**登入名人堂**（打赢冠军），并且**收服满 60 种关都宝可梦**。然后回真新镇找大木博士，图鉴升级成全国图鉴。

> 60 种是"收服"，图鉴里只"见过"的不算。

### 3. 红宝石

回第一岛找锦辉，他托你找**红宝石**。这时**灯火山右侧洞口**的 2 个火箭队手下才肯对战，打赢后进洞，最底层的盲文房间里拿红宝石。

> 顺手听密码：灯火山门口的火箭队手下会说出**火箭队仓库的第一个密码**，第 7 步要用。

### 4. 七彩通行船券

红宝石交给锦辉，**三岛通行船券**换成**七彩通行船券**，第四到第七岛开放。

## 后半：再追回蓝宝石（第 5–8 步）

### 5. 冻瀑洞窟（第四岛）

在洞里拿到秘传招式**攀瀑**（走法见[秘传招式](../tm-hm/hidden-machines.md#7-攀瀑秘传07)），爬上瀑布到最深处，帮四天王**科拿**赶走火箭队。

### 6. 点之穴（第六岛 遗迹山谷）

第 5 步做完，门口的研究员**澄夫**才让开。用**居合劈**开门，按石碑盲文的方向跳洞，拿到**蓝宝石**——却被澄夫抢走，他留下**第二个密码**。

### 7. 火箭队仓库（第五岛空地）

两个密码凑齐才进得去，打赢澄夫拿回蓝宝石。

### 8. 交蓝宝石（第一岛 锦辉）

网络机器修好，七之岛主线完结。同时解锁：

- **超梦 Lv70**：华蓝洞窟门口的人让开，超梦在最深处；
- **三圣兽之一**开始在关都游走：开局选杰尼龟 → 雷公，妙蛙种子 → 炎帝，小火龙 → 水君。

## 卡住了？对照这张表

| 卡住的现象 | 缺的是 |
|---|---|
| 大木博士不给全国图鉴 | 还没登入名人堂、收服不到 60 种（只见过不算），或第 1 步陨石剧情没做 |
| 锦辉一直说在改机器 | 还没拿全国图鉴 |
| 灯火山火箭队不让进洞 | 还没听锦辉托付找红宝石 |
| 船只到第一至三岛 | 红宝石没交，船券还是三岛通行船券 |
| 点之穴门口有人挡着 | 先去第四岛冻瀑洞窟赶走火箭队 |
| 华蓝洞窟进不去 | 蓝宝石还没交给锦辉 |
| 有船票却去不了肚脐岩 | 先拿七彩通行船券，枯叶市港口才有航线（按原版脚本） |

## Switch 版的船票

Switch 版**登入名人堂后直接给神秘船票、极光船票**，不用配信。但按原版脚本，要先拿到第 4 步的**七彩通行船券**，枯叶市港口才有去肚脐岩和诞生之岛的航线。

- 肚脐岩：山顶是**凤王**、最深处是**洛奇亚**，两只都能抓；
- 诞生之岛：**代欧奇希斯**，抓法见[必抓宝可梦](../pokedex/must-catch.md#16-代欧奇希斯lv30)。

卡住了就看这条链上缺的是哪一步，补上就能往下走。

## 本页的局限

- 七之岛的地名和人物（锦辉、小迷、澄夫、点之穴、遗迹山谷等）火红叶绿没有官方中文版，采用神奇宝贝百科的通用译名。
- 神奇宝贝百科对七彩通行船券的发放时机有两种说法；本页按火红叶绿反编译脚本写成"交红宝石时换"，没有实机验证。
- Switch 版的航线条件是按原版脚本推断的，官方没有单独说明。
- 没写两个密码的原文（因语言版本而异），也没写点之穴跳洞的具体方向顺序。
