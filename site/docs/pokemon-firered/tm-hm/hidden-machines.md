# 7 个秘传招式：在哪拿、干嘛用

"砍树怎么学""冲浪在哪拿"是火红叶绿问得最多的问题。这一页把 7 个秘传招式按拿到的先后排好：**在哪拿、拿来干嘛、要哪枚徽章**。

**秘传招式**（HM）和普通的招式学习器（TM）不同：

- 可以反复使用，教给多只宝可梦；
- 除了对战，还能在**野外**用来砍树、冲浪、推石头，推进剧情离不开它们；
- 野外使用要先拿到对应的**徽章**；对战里学了就能用；
- 学会后**不能直接忘掉**，要去浅红市找**遗忘爷爷**。

主线真正离不开的只有 3 个：**居合劈**砍道馆前的树、**冲浪**去红莲镇、**怪力**过冠军之路。其余 4 个按需拿。

## 每个秘传干嘛用、对战值不值得带

"威力 / 命中"按火红叶绿的数值。除居合劈、怪力外，其余 5 招后来的作品都改过数值，别拿朱紫的数据套。

| 招式 | 野外用来做什么 | 对战（属性 · 威力 / 命中） |
|---|---|---|
| 居合劈 | 砍掉挡路的小树，还能割掉身边 3×3 的草丛。枯叶道馆、玉虹道馆门口都要砍 | 一般 · 50 / 95，偏弱，路上过渡 |
| 闪光 | 照亮漆黑的洞窟，主要用在 10 号道路的岩山隧道 | 降对手命中 1 级；本作命中只有 70 |
| 飞翔 | 在室外使用，飞回去过的城镇和宝可梦联盟，跑图全靠它 | 飞行 · 70 / 95，第 1 回合飞上天 |
| 冲浪 | 在水面上移动。去红莲镇道馆、无人发电厂抓闪电鸟都要 | 水 · 95 / 100，双打打对面两只 |
| 怪力 | 推动巨石。冠军之路要把石头推上按钮才能前进，双子岛靠推石头挡水流 | 一般 · 80 / 100，前中期够用 |
| 碎岩 | 打碎裂开的岩石，碎石时可能跳出野生宝可梦。灯火山去火焰鸟那里要用 | 格斗 · 20 / 100，50% 降防御 1 级 |
| 攀瀑 | 登上或跃下大瀑布。冻瀑洞窟去洞底要用 | 水 · 80 / 100，本作没有畏缩效果 |

最适合长期当主力输出的是**冲浪**。

## 前期：居合劈 + 闪光（第 2–3 馆之间）

### 1. 居合劈（秘传01）

路线：25 号道路 → 华蓝市 → 地下通道 → 枯叶市港口

先在 25 号道路的海角小屋帮**正辉**，拿到**船票**。南下枯叶市，从港口登上**圣特安努号**，上 2F 船长室，船长给居合劈。

顺手拿：1F 房间 2 的招式学习器31（劈瓦）、B1F 房间 2 的招式学习器44（睡觉）。

> 旧攻略里的"居合斩"，现行官方译名是**居合劈**。

### 2. 闪光（秘传05）

路线：枯叶市 → 11 号道路 → 地鼠洞穴 → 2 号道路东侧

2 号道路分东西两条，东边那条要砍树才进得去。最顺的走法：枯叶市往东进 11 号道路，钻**地鼠洞穴**，出口就在 2 号道路东侧，往南进闸口找**大木博士的助手**。

条件：图鉴里**收服满 10 种**（只看到不算）。

## 中期：飞翔 + 冲浪 + 怪力（第 4–5 馆前后）

### 3. 飞翔（秘传02）

路线：玉虹市 → 西出口 → 16 号道路

出玉虹市往西，砍掉栅栏旁的小树，进左上角民房，屋里的女子给飞翔。卡比兽睡在南边闸口，**不用叫醒它也能拿**。

### 4. 冲浪（秘传03）

路线：浅红市北 → 狩猎地带 → 一路往西 → 西区

花 $500 进**狩猎地带**（送 30 个狩猎球，限 600 步）。直奔西区，最里面的**秘密屋**里的男人给冲浪；西区中部地上捡**金假牙**。

步数用完会被请出去，再付一次 $500 进去接着找就行。

> 冲浪用不了？要先打赢浅红道馆**阿桔**拿粉红徽章。道馆也在浅红市，拿完徽章就能下水。

### 5. 怪力（秘传04）

路线：狩猎地带 → 浅红市园长家

把**金假牙**还给狩猎地带园长，他送怪力。学会后回园长家，推开屋里的巨石，后面有一颗**神奇糖果**。

## 七之岛：碎岩 + 攀瀑（第 7 馆后）

### 6. 碎岩（秘传06）

路线：红莲镇 → 船 → 第一岛 → 往北 → 热气之路

打赢夏伯后跟正辉去第一岛，拿到三岛通行船券。往北走**热气之路**，路中间的**灯火温泉**里，老人给碎岩。

用处：灯火山抓火焰鸟要碎岩 + 怪力开路。

### 7. 攀瀑（秘传07）

路线：通关后 → 第四岛 → 冻瀑洞窟内部洞窟

进入名人堂、开放第四岛之后才能拿（怎么开放见[通关后解锁](../sevii-islands/postgame-unlock.md)）。进**冻瀑洞窟**的内部洞窟，下到下层滑冰区，借冰面上的石头停住，从南端梯子爬回上层，入口东边的岩架上就是。

用处：攀上瀑布到洞底，帮四天王科拿赶走火箭队；洞底水面能遇到野生拉普拉斯。

## 3 个常见误区

1. **学了用不了**：先看上面总览表"野外用要"那枚徽章拿到没有。
2. **"居合斩"找不到**：旧译名，现在叫居合劈。
3. **秘传招式忘不掉**：不能直接用新招式覆盖，要到浅红市的遗忘爷爷那里删。
